⚙️ Impostazioni

🏷️ Le mie categorie
Queste categorie compaiono nel menu a tendina quando aggiungi o modifichi un libro.
🔑 Chiave Google Books (facoltativa)
Senza chiave Google Books limita le richieste (errore 429) e molti libri italiani non vengono trovati. Con una chiave gratuita la ricerca funziona in modo affidabile.
🔄 Sincronizzazione GitHub
Salvataggio automatico ad ogni modifica e caricamento automatico all'apertura dell'app. Il token resta solo su questo dispositivo. Usa un token fine-grained limitato al repo privato, permesso "Contents: Read and write".
💾 Backup locale
L'import unisce i libri del file a quelli presenti, senza cancellare nulla.
